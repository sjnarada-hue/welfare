# 학과 도우미 (챗봇 앱)

사회복지 야간학과 학생(성인학습자)이 **학교 홈페이지 로그인, 줌·팀즈 접속, 과제 제출**에서 막혔을 때
폰에서 바로 열어 물어보는 학과 전용 챗봇 앱입니다.

- 앱스토어 설치 없이 **링크 하나로 열고, 홈 화면에 추가하면 앱처럼** 아이콘으로 실행됩니다(PWA).
- 안드로이드·아이폰·PC 어디서나 같은 화면이라, 기종마다 설명서 화면이 달라지는 문제가 없습니다.

> 아이디어: 버튼 → AI → 사람 순서로 받쳐 준다.

## 동작 방식

| 단계 | 언제 | 무엇을 |
|---|---|---|
| 1. 큰 버튼 | 첫 화면 / 버튼을 누르거나 짧게 물을 때 | `data/knowledge.json`에 적어 둔 **정해진 답**과 바로가기 링크 |
| 2. AI | 버튼에 없는 질문을 쓸 때 | Claude가 **학과 자료만 근거로** 쉬운 말·번호 순서로 답함 |
| 3. 사람 | "해결 안 됐어요" / AI가 답할 수 없을 때 / 직접 요청 | 교수·조교 카드에서 **전화하기 / 이메일 보내기** 버튼 |

첫 화면 버튼:

1. 학교 홈페이지 로그인이 안 돼요
2. 줌·팀즈 들어가는 법 알려주세요
3. 과제는 어디에 내요?
4. 비밀번호를 잊어버렸어요
5. 교수님(조교)께 직접 물어보기

### 성인학습자를 위한 기능

- **글씨 크게** 버튼(설정은 기억됨), 큰 버튼과 넉넉한 글자 크기
- **🔊 읽어주기**: 답변을 소리로 읽어 줍니다.
- **🎤 말로 묻기**: 글을 쓰기 어려우면 말로 질문합니다(크롬·삼성인터넷 등 지원 브라우저에서만 보임).
- **홈 화면에 추가 안내**: 안드로이드는 '추가하기' 버튼, 아이폰은 공유 버튼 사용법을 띄웁니다.
- 어두운 화면(다크 모드) 자동 지원, 인터넷이 끊기면 알기 쉽게 안내하고 '다시 시도' 버튼 제공

### 안전장치

- **개인정보 차단**: 학번·비밀번호·주민번호로 보이는 내용이 오면 AI로 보내지 않고 저장하지 않으며, 쓰지 말라고 안내합니다. (`app/privacy.py`)
- **비밀번호 분실·계정 잠김**은 챗봇이 풀 수 없으므로 전산 담당 부서로 안내합니다.
- **AI가 학교 정보를 지어내지 않도록** 학과 자료에 없는 사실은 "확인이 필요해요"라고 답하고 사람 연결을 권합니다. AI 답변에는 'AI 답변 · 틀릴 수 있어요' 표시가 붙습니다.
- API 키가 없거나 AI가 실패해도 **버튼 답변과 사람 연결은 그대로 동작**합니다.
- 대화 내용은 서버 메모리에 최근 몇 턴만 30분간 보관하고(후속 질문 이해용) 파일로 저장하지 않습니다.

## 폴더 구조

```
data/knowledge.json         ← 학과 정보·버튼·답변 (여기만 고치면 됩니다)
app/bot.py                  ← 버튼 → AI → 사람 흐름
app/ai.py                   ← Claude 호출(학과 자료 근거)
app/privacy.py              ← 개인정보 감지
app/main.py                 ← 웹 서버(API)
app/static/index.html       ← 앱 화면
app/static/manifest.webmanifest, sw.js, icons/  ← 홈 화면 설치용
tests/                      ← 자동 테스트
```

## 1. 먼저 학과 정보 채우기

`data/knowledge.json`의 `[대괄호]` 값과 `example.ac.kr` 주소를 실제 정보로 바꿉니다.

- `department`: 앱 이름, 학교 홈페이지·포털·LMS 주소, 전산실 전화, 교수·조교 연락처
  (연락처의 전화번호·이메일이 실제 값이면 '전화하기', '이메일 보내기' 버튼이 생깁니다)
- `menu`: 버튼 문장(`message`), 정해진 답(`answer`), 바로가기(`links`)
- `extra_faq`: 버튼에는 없지만 AI가 참고할 질문과 공식 답변

> AI 답변은 틀릴 수 있으니, 주요 질문은 직접 물어보고 확인해 두세요.

## 2. 내 컴퓨터에서 실행해 보기

```bash
pip install -r requirements-dev.txt
```

```bash
export ANTHROPIC_API_KEY=sk-ant-...   # 없으면 AI 없이 버튼 + 사람 연결만 동작

```


## 3. 학생들에게 배포하기

홈 화면에 추가(앱 설치)는 **https 주소**에서만 동작하므로 인터넷 서버에 올려야 합니다.

1. 서버에 올립니다. **Vercel(권장, 무료 플랜 가능)** 설정이 들어 있습니다(`vercel.json`, `api/index.py`).
   1. https://vercel.com 에 GitHub 계정으로 로그인합니다.
   2. **Add New… → Project** → `welfare` 저장소 옆 **Import**를 누릅니다.
   3. Framework Preset은 **Other** 그대로 두고, **Environment Variables**에 `ANTHROPIC_API_KEY`를 넣습니다(AI 답변을 쓸 때만).
   4. **Deploy**를 누르면 1~2분 뒤 `https://프로젝트이름.vercel.app` 주소가 나옵니다.
   5. 이후 GitHub에 올라가는 변경(예: `data/knowledge.json` 수정)은 자동으로 다시 배포됩니다.
      브랜치가 `main`이 아니면 **Settings → Git → Production Branch**에서 배포할 브랜치를 고르세요.

   다른 곳에 올릴 때:
   - Render / Railway 등: 실행 명령을 `uvicorn app.main:app --host 0.0.0.0 --port $PORT`로 지정
   - Docker를 쓰는 서버(학교 서버, Cloud Run 등): 포함된 `Dockerfile` 사용
2. AI 답변을 쓰려면 서버 환경변수에 `ANTHROPIC_API_KEY`를 넣습니다.
   > Vercel에서는 요청마다 서버가 새로 뜰 수 있어, "그 다음엔요?" 같은 이어지는 질문의 앞 대화를 놓칠 수 있습니다. 버튼·한 번에 묻는 질문은 문제없습니다.
3. 받은 https 주소를 QR 코드로 만들어 첫 수업에서 함께 열고, **홈 화면에 추가**까지 같이 해 둡니다.
   - 안드로이드: 화면 위 '추가하기' 버튼, 또는 브라우저 메뉴 → '홈 화면에 추가'
   - 아이폰(사파리): 아래 공유 버튼(□↑) → '홈 화면에 추가'
4. 학과 단톡방·공지에 같은 주소를 올려 두면 언제든 다시 열 수 있습니다.

## 4. 설정값 (환경변수)

| 이름 | 기본값 | 설명 |
|---|---|---|
| `ANTHROPIC_API_KEY` | (없음) | Claude API 키. 없으면 AI 단계를 건너뜁니다. |
| `CLAUDE_MODEL` | `claude-opus-5-5` | 사용할 모델 |
| `CLAUDE_EFFORT` | `low` | 답변 깊이(`low`/`medium`/`high`). 빠른 안내용이라 `low` 권장 |
| `KNOWLEDGE_PATH` | `data/knowledge.json` | 학과 자료 파일 위치 |

AI 호출에는 프롬프트 캐시(학과 자료 부분)와, 드물게 안전 분류기가 일반 질문을 거절할 때 다른 모델로 다시 답하게 하는
서버 측 대체(`fallbacks: "default"`)가 켜져 있습니다.
