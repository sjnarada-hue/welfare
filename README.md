# 학과 전용 카카오톡 챗봇

사회복지 야간학과 학생(성인학습자)이 **학교 홈페이지 로그인, 줌·팀즈 접속, 과제 제출**에서 막혔을 때
익숙한 카카오톡 채널 안에서 바로 답을 찾도록 돕는 챗봇입니다.

> 아이디어: "익숙함이 곧 접근성" — 버튼 → AI → 사람 순서로 받쳐 준다.

## 동작 방식

| 단계 | 언제 | 무엇을 |
|---|---|---|
| 1. 큰 버튼 | 첫 화면 / 버튼을 누르거나 짧게 물을 때 | `data/knowledge.json`에 적어 둔 **정해진 답**과 바로가기 링크 |
| 2. AI | 버튼에 없는 질문을 채팅으로 쓸 때 | Claude가 **학과 자료만 근거로** 쉬운 말·번호 순서로 답함 |
| 3. 사람 | "해결 안 됐어요" / AI가 답할 수 없을 때 / 직접 요청 | 교수·조교 연락처 + 카카오 **상담원 연결(1:1 채팅)** 버튼 |

첫 화면 버튼(문서의 예시 그대로):

- 학교 홈페이지 로그인이 안 돼요
- 줌·팀즈 들어가는 법 알려주세요
- 과제는 어디에 내요?
- 비밀번호를 잊어버렸어요
- 교수님(조교)께 직접 물어보기

### 안전장치 (문서의 '주의할 점' 반영)

- **개인정보 차단**: 학번·비밀번호·주민번호로 보이는 내용이 오면 AI로 보내지 않고 저장하지 않으며, 쓰지 말라고 안내합니다. (`app/privacy.py`)
- **비밀번호 분실·계정 잠김**은 챗봇이 풀 수 없으므로 전산 담당 부서로 안내합니다.
- **AI가 학교 정보를 지어내지 않도록** 학과 자료에 없는 사실은 "확인이 필요해요"라고 답하고 사람 연결을 권하게 했습니다. 웹 테스트 화면에는 'AI 답변 · 틀릴 수 있어요' 표시가 붙습니다.
- API 키가 없거나 AI가 실패해도 **버튼 답변과 사람 연결은 그대로 동작**합니다.

## 폴더 구조

```
data/knowledge.json   ← 학과 정보·버튼·답변 (여기만 고치면 됩니다)
app/bot.py            ← 버튼 → AI → 사람 흐름
app/ai.py             ← Claude 호출(학과 자료 근거)
app/kakao.py          ← 카카오 i 오픈빌더 응답 형식
app/privacy.py        ← 개인정보 감지
app/main.py           ← 웹 서버 (카카오 스킬 / 테스트 화면)
app/static/index.html ← 카카오톡처럼 생긴 테스트 화면
tests/                ← 자동 테스트
```

## 1. 먼저 학과 정보 채우기

`data/knowledge.json`의 `[대괄호]` 값과 `example.ac.kr` 주소를 실제 정보로 바꿉니다.

- `department`: 학교 홈페이지·포털·LMS 주소, 전산실 전화, 교수·조교 연락처
- `menu`: 버튼 이름(`label`), 버튼을 누르면 보내지는 문장(`message`), 정해진 답(`answer`), 바로가기(`links`)
- `extra_faq`: 버튼에는 없지만 AI가 참고할 질문과 공식 답변

> 문서의 "학생들이 실제로 가장 많이 묻는 질문을 모아 버튼 항목 확정" 단계에서 이 파일을 고치면 됩니다.
> AI 답변은 틀릴 수 있으니, 주요 질문은 직접 물어보고 확인해 두세요.

## 3. 카카오톡 채널에 연결하기

1. **카카오톡 채널 만들기** — [카카오비즈니스](https://business.kakao.com)에서 학과 채널을 만들거나, 대학 기존 채널에 붙일지 결정합니다.
2. **서버 올리기** — 이 프로그램을 HTTPS 주소가 있는 서버(학교 서버, Render, Railway, Cloud Run 등)에 올립니다.
   실행 명령: `uvicorn app.main:app --host 0.0.0.0 --port $PORT`
3. **카카오 i 오픈빌더**(https://chatbot.kakao.com)에서 봇을 만들고 채널과 연결합니다.
4. **스킬 등록** — `스킬` 메뉴 → 새 스킬 → URL에 `https://내서버주소/kakao/skill` 입력.
   (선택) 헤더 `X-Skill-Token` 값을 정하고 서버 환경변수 `KAKAO_SKILL_TOKEN`에 같은 값을 넣으면 다른 곳의 요청을 막을 수 있습니다.
5. **시나리오 연결** — `웰컴 블록`과 `폴백 블록`의 응답을 모두 **스킬 데이터 사용**으로 바꾸고 위 스킬을 고릅니다.
   - 웰컴 블록: 채널 추가 직후 큰 버튼 메뉴가 나옵니다.
   - 폴백 블록: 학생이 쓰는 모든 말이 이 서버로 와서 버튼/AI/사람 순서로 처리됩니다.
6. **AI 답변 콜백 켜기(권장)** — 카카오는 5초 안에 답해야 합니다. AI 답변은 더 걸릴 수 있으므로
   폴백 블록 설정에서 **'Callback 설정'(AI 챗봇 콜백)** 을 켜 주세요. 켜면 "답을 찾고 있어요…"를 먼저 보내고 최대 1분 안에 AI 답이 이어서 옵니다.
   (콜백 기능은 오픈빌더에서 별도 신청이 필요할 수 있습니다. 끄면 4초 안에 못 끝난 질문은 "잠시 후 다시" 안내로 대신합니다.)
7. **상담원 연결** — 채널 관리자센터에서 1:1 채팅을 켜 두면 '상담원 연결' 버튼으로 조교와 바로 대화할 수 있습니다.
8. **배포** 후 첫 수업 때 학생들과 함께 채널을 친구 추가합니다.

## 4. 설정값 (환경변수)

| 이름 | 기본값 | 설명 |
|---|---|---|
| `ANTHROPIC_API_KEY` | (없음) | Claude API 키. 없으면 AI 단계를 건너뜁니다. |
| `CLAUDE_MODEL` | `claude-opus-5-5` | 사용할 모델 |
| `CLAUDE_EFFORT` | `low` | 답변 깊이(`low`/`medium`/`high`). 카톡 안내용이라 빠른 `low` 권장 |
| `KAKAO_SKILL_TOKEN` | (없음) | 스킬 요청 헤더 검사용 값 |
| `SYNC_AI_TIMEOUT` | `4.0` | 콜백을 안 쓸 때 AI 답을 기다릴 최대 초 |
| `KNOWLEDGE_PATH` | `data/knowledge.json` | 학과 자료 파일 위치 |

AI 호출에는 프롬프트 캐시(학과 자료 부분)와, 드물게 안전 분류기가 일반 질문을 거절할 때 다른 모델로 다시 답하게 하는
서버 측 대체(`fallbacks: "default"`)가 켜져 있습니다.
